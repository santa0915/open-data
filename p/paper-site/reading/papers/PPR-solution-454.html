要点

Problem / TaskLLMエージェントによる科学的方法論（仮説・実装・検証・フィードバック）の自動化とアルゴリズム発見
Main ContributionScientistエージェントとKuhnエージェントからなる反復探索フレームワーク「The Little Scientist」の提案。構造化診断フィードバックとパラダイム転換機構により、GPU不要・低コストで解釈可能な古典的アルゴリズム（DALE, Delta V）を自律発見
Noveltyスカラー適合度ではなくインスタンス別構造化診断フィードバックを採用し探索効率を向上。局所最適脱出にKuhnエージェントによる分野横断的インスピレーション注入と潜在空間強制転移を実装。進化計算に依存せず仮説駆動型コード生成で幻覚問題を回避

要約

LLMエージェントに科学的方法論（仮説立案→実装→検証→フィードバック）を適用し、アルゴリズム設計を自動化する「The Little Scientist」フレームワークを提案。局所最適で停滞した際、「Kuhnエージェント」が学際的な発想を注入して探索空間を切り替えるメカニズムを採用。タンパク質適合度予測とDNAモチーフ発見の2課題で評価し、それぞれ新規アンサンブル戦略「Delta V」とゼロから記述したアルゴリズム「DALE」を発見。両タスクで既存SOTAを凌駕する性能を示し、GPU不要・単一VMでの低コスト動作を実証。

キーポイント

新規性: LLMエージェントに科学的方法論のサイクルを明示的に組み込み、ハイパーパラメータ調整ではなく「新規アルゴリズム/戦略の自律的発見」を目指す点。

技術的貢献: 探索停滞時に学際的インスピレーションを注入する「Kuhnエージェント」と、構造化診断フィードバックを用いた反復改善パイプラインの設計。

実験結果: ProteinGymベンチマークで全5指標1位（+0.033 Spearman）、DNAモチーフ発見でSTREMEより精度向上かつ11倍高速化を実現。

実用性: GPU不要・単一VMで7億トークン規模の探索を完遂可能と、低コストかつ高拡張性の実装を示唆。

限界・課題: 生体情報学領域に限定された検証であり、Kuhnエージェントの注入品質依存性や他ドメインへの一般化可能性は未解決課題となる。

手法

The Little Scientist Framework LLM Agent / Algorithm Discovery

Scientistエージェント（内側ループ）、評価環境、Kuhnエージェント（外側ループ）の3コンポーネント連携。内側ループは仮説形成→コード生成→スモークテスト→本番検証→Reconciliation phaseによる予測照合を反復。外側ループはベンチマーク設定とパラダイム転換トリガーを管理

効く条件
低コスト評価環境、解釈可能なアルゴリズム発見が必要、コードグラウンディングによる幻覚回避が求められる場合
効かない条件
スカラーフィードバックのみの場合（盲目のランダム探索に退化）、サンドボックス制約違反時

重要ハイパラ: 探索停滞トリガー（7〜10回の非改善イテレーション）、スモークテストサイズ（4〜5インスタンス）、モチーフ幅範囲（6〜17塩基対）

Kuhn Agent Exploration Strategy / Agent Architecture

Scientistの探索停滞時にトリガー。過去の探索履歴を意図的に除外し、ランダム生成された「パラダイム転換仮説」と「他分野インスピレーション」をプロンプト注入。同一基盤LLMの潜在表現空間を強制転移させる

効く条件
エージェントが局所最適で停滞し、既存の設計空間内では改善が見込めない場合
効かない条件
注入された仮説が文脈と乖離している場合（必ずしもスコア向上を保証しない）

重要ハイパラ: トリガー閾値（7〜10回）、注入コンテキストの分野横断性

Delta V Ensemble Correction Strategy / Algorithm Discovery

タンパク質適合度予測用のアンサンブル補正戦略。信頼度スコアに基づく逐変異重み調整、近傍位置間での残差伝播、べき乗変換による出力分布拡張からなる静的校正戦略

効く条件
ProteinGym DMSベンチマーク、推論時の動的LLM推論コストを排除したい場合
効かない条件
モデル出力の信頼度分布が実際の適合性と相関しない場合

重要ハイパラ: 信頼度閾値、残差伝播範囲、べき乗変換の指数

DALE Motif Discovery Algorithm / Algorithm Discovery

DNAモチーフ発見用de novoアルゴリズム。abundance基準とconsistency基準を統合したdual-seed selection、ソフトEM法による20イテレーション収束制御、有効幅（6種類）を考慮したスコアリング、判別スコアと幅効率性のPareto frontに基づく多目的ランキング

効く条件
ENCODE K562 ChIP-seqデータ、事前ドメイン知識なしで高速かつ高精度なモチーフ発見が必要な場合
効かない条件
配列長や背景モデルの分布がベンチマーク条件と大きく乖離した場合

重要ハイパラ: モチーフ幅範囲（6〜17bp）、EMイテレーション数（20）、Pareto frontの重みバランス
