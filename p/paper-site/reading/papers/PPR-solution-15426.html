要約

LLM駆動エージェントのツール呼び出し軌跡を制御する行動ベースファイアウォールを提案。検証済みの良性シーケンスとパラメータ範囲をpDFA（パラメータ化決定性有限オートマトン）にコンパイルし、オンライン実行はO(1)状態遷移ルックアップのみで高速強制する。Agent Security Benchでマルチステップ攻撃成功率0%を達成し、既存SOTA比3.7倍の高速化を実現。ただし連続パラメータ境界の維持が困難な場合、同義語置換攻撃に脆弱であるため厳密ホワイトリスト併用が必要。

キーポイント

新規性: LLMエージェントのツール呼び出しシーケンスをpDFAでモデル化し、行動軌跡ベースの異常検知ファイアウォールを実現

技術的貢献: 重たい分析をオフラインに分離し、オンライン実行はO(1)の高速状態遷移ルックアップのみで処理する軽量ゲートウェイ設計

実験結果: Agent Security Benchで攻撃成功率5.6%（構造化ワークフロー内2.2%）、マルチステップ/文脈依存攻撃に対して0%を達成し既存SOTAを大幅上回る

実用性・限界: 1呼び出しあたり2.2msの低レイテンシと2.0%の良性タスク失敗率を実現する一方、連続パラメータ境界の維持が困難な場合、同義語置換攻撃（18%回避率）に脆弱
