要約

AIエージェントのガードレールがセッションを跨ぐ分散攻撃に対して脆弱であることを明らかにし、検出のためのベンチマーク「CSTM-Bench」と評価アルゴリズムを提案。既存のセッション単位判定やフルログ相関器は検出率が半分以下に低下する一方、限られたメモリ(K=50)で高信号断片を保持するCoreset Memory Readerと順序安定性指標(CSR_prefix)を融合した新手法により、分散攻撃でも検出率を維持可能であることを実証。

キーポイント

既存のセッション単位判定では検出できないクロスセッション攻撃を検出・評価するための初のベンチマーク(CSTM-Bench)を公開

フルログ相関器は検出率が著しく低下することを明らかにし、限られたメモリ(K=50)で重要断片を保持するCoreset Memory Readerアルゴリズムを提案

順序安定性指標(CSR_prefix)とF1スコアを融合したCSTM評価指標を定義し、検出率と推論安定性のトレードオフを可視化

データセット・コードをHugging Faceで公開しており、エージェントセキュリティ実装の指針として直接活用可能

相関器は単一LLM(Claude)に限定されプロンプト最適化も未実施。マルチプロバイダー対応や大規模化が今後の課題
