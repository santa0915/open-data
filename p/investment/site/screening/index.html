銘柄スクリーニング

スクリーニングの価値は「今日の 1 位」ではなく、何度も出てくる銘柄にある。 実施 24 回分を、条件・常連度・次の一手の順に畳んで見る。

スクリーニングから先の流れ

一覧は銘柄選定の入口であって結論ではない。 条件を満たし続ける銘柄をカルテに載せ、仮説・計画・監視まで通して初めて売買になる。

  1. L1 起票
    条件を満たし続ける銘柄をカルテに載せる
    invest.py workflow run L1-L2_candidate_to_research
  2. L2 研究
    決算・材料を集めて投資仮説を書く
    /stock-portfolio thesis create --symbol <銘柄>
  3. L3 プラン
    エントリー帯・目標・撤退を決める
    /stock-trading-strategy plan <銘柄>
  4. L4 保有
    建てた玉を毎朝の売りルール監視に載せる
    invest.py workflow run L4-L5_dossier_daily_collect
