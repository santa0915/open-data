イチモン 取得テーマカタログ

中学受験の社会・理科の問題を作るために、事実データをどこからどう取るかを 100テーマ分そろえた定義集です。Wikidata の SPARQL クエリ89本と、 e-Stat の統計表の指定を含みます。学習アプリ「イチモン」で実際に使っている定義をそのまま公開しています。

大事な注意 — 100本のうち、実際に動かして確認できているのは17本です。

この環境から Wikidata / e-Stat へ到達できない状態で書いた下書きが多く含まれます。 各テーマの status を必ず見てください。0件が返ったらクエリ側の調整が要ります。

ファイル

  • themes.json全フィールド。SPARQL 本文つき
  • themes.csv表計算で開ける平板版。SPARQL は含みません

使い方

たとえば「地理で、実際に動作確認できているテーマ」だけを取り出すには:

jq '.themes[] | select(.area == "chiri" and .status == "live-verified") | {id, topic}' themes.json

sparql の中身は Wikidata Query Service にそのまま貼り付けて実行できます。
